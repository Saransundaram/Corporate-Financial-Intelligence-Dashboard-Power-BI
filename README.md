# Corporate Financial Intelligence Dashboard

## Project Overview
This project analyzes and compares the financial performance of Tesla, Ford, and General Motors using Microsoft Power BI.

The dashboard provides insights into:

- Revenue Performance
- Gross Profit Analysis
- Net Income Trends
- Free Cash Flow Analysis
- Return on Equity (ROE)
- Gross Margin %
- Net Profit Margin %
- Current Ratio
- Asset Growth Trends

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Excel

## Dashboard Pages

### 1. Executive Overview
Provides KPI cards and high-level financial insights.

### 2. Company Comparison
Compares Tesla, Ford, and GM across key financial metrics.

### 3. Financial Trends Analysis
Shows year-over-year performance trends from 2020–2025.

## Key Features

- Interactive Company Slicer
- Year-wise Filtering
- KPI Monitoring
- Comparative Analysis
- Trend Analysis

## Dataset

Financial Statement Data:
- Income Statement
- Balance Sheet
- Cash Flow Statement

Period Covered:
2020 – 2025
